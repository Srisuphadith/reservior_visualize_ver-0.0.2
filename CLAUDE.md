# CLAUDE.md

## Project Goal

Build web app 3D map visualize water level in reservior in thailand

## Engineering Rules

1. Read README.md before making changes.
2. Add tests before deployment.
3. Every feature must have tests.
4. Never modify production configuration without verification.

## Development Workflow

1. Analyze requirements.
2. Create architecture.
3. Create implementation plan.
4. Implement incrementally.
5. Run tests.
6. Build Docker image.
7. Run integration tests.
8. Prepare deployment.
9. Deploy only after verification.

## Git Rules

- Use meaningful commits.
- Do not commit secrets.
- Do not commit generated build artifacts.
